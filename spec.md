# Personal Blog Spec

This is the spec for my personal blog. It contains details about the style, pages, and posts.

## Framework and Theme

The site is built using Jekyll and on top of the [Hacker](https://github.com/pages-themes/hacker) theme. The theme uses dark colors and clean visuals, but is not exactly how I want it to look. Any files currently in the repo are simply a baseline, and can and should be modified or even removed when necessary. The other sections of this spec will detail the changes I plan to make.

## Style

The site will use a dark color scheme with a clean, modern look. The font will be Roboto Mono, and the site will have a fixed width and centered layout. The background should be an easy-on-the-eyes dark-grey color, and the text should be primarily white, with highlight text (such as buttons and links) being a comfortable shade of yellow. The site should be extremely simple.

## Pages

The site will have several pages: a "Home" page, a "Writeups" page, and then individual pages for each writeup, which will be subpages of the "Writeups" page.

The top of each page should have a header with the site title and a navigation bar with links to the "Home" page and the "Writeups" page.

The "Home" page should have a short description of the site and a list of links to the "Writeups" page and any other pages I may add in the future.

The "Writeups" page should have a list of links to the individual writeup pages.

### Writeups

Once a specific writeup is clicked on, the page should have the title of the writeup, a description, and a list of links to the "Home" page and the "Writeups" page.

The page should also contain the content of the writeup, which will be in markdown format.
