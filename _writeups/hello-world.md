## Why this exists

This is a sample writeup you can use as a template.

It demonstrates:

- A brief intro section
- Headings and subheadings
- Inline code like `bundle exec jekyll serve`
- A code block with syntax highlighting
- A short list of takeaways

## A tiny workflow

1. Create a new markdown file in `_writeups/`
2. Add frontmatter (`title`, `description`, `date`, `tags`)
3. Write in Markdown
4. Commit and push

## Takeaways

- Keep writeups simple and consistent
- Use `description` to make the Writeups index scannable
- Use `tags` only if they add real navigation value
